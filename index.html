2Jana lesen

Tampal mesej permintaan pelanggan. ID Mesin dan produk dikesan secara automatik.

Contoh di atas. ID Mesin dipaparkan pada skrin Pengaktifan Lesen simulator.
Lesen kekal: tiada tarikh tamat dan tanpa had penggunaan, tetapi hanya sah pada komputer dengan ID Mesin ini. Jika disalin ke PC lain, ia ditolak. Jika pelanggan menukar cakera atau memasang semula Windows, ID Mesin berubah dan lesen baharu diperlukan.
